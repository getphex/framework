# SQLite CRUD example

A complete PDO application with prepared SQL, typed row mapping, named routes
and request-owned transactions.

Follow the [SQLite CRUD tutorial](../../docs/database-tutorial.md) from the
framework repository root to initialize its database and run PHP or native HTTP.
The [database guide](../../docs/database.md) explains how to add the adapter to
your own application. [Native servers](../../docs/native.md) covers retained
connections, workers and runtime requirements.
